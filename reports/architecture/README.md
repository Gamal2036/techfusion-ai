# Reports — Architecture

> **Purpose:** Architecture decisions and architecture review records.
> **Owner:** Engineering Execution Governance
> **Last Updated:** 2026-08-01

---

## What belongs here

- Architecture review records for proposed changes
- Architecture decisions and their rationale
- Impact analysis for changes that cross system boundaries

## Process

- Use the `templates/architecture-review.md` template
- A change that can no longer be isolated is an architecture event, not an implementation (TG-CORE Section 2)
- Stop, explain, and escalate on architecture conflicts (TG-CORE Section 13)
